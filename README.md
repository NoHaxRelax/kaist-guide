# KAIST, the short version

A quick, honest overview of an exchange semester at KAIST in Daejeon, South Korea, for DTU students, from my fall 2025 exchange.

Read it at **https://nohaxrelax.github.io/kaist-guide/**

- `docs/index.html` is the whole site: one static page, served by GitHub Pages. Edit it directly.
- `draft/` holds the long version of the guide (about 18,000 words, 11 sections) that the overview was cut down from.

Facts are from fall 2025 unless marked. This is not an official DTU or KAIST page.
